# Тестирование веб-приложения Codebattle

[![Autotests Status](https://github.com/Skifca/qa-engineer-java-from-scratch-project-85/workflows/hexlet-check/badge.svg)](https://github.com/Skifca/qa-engineer-java-from-scratch-project-85/actions)

## Описание проекта
Проект посвящен проведению полного цикла ручного тестирования игровой веб-платформы Codebattle, предназначенной для соревновательного программирования между разработчиками в режиме реального времени. 

В ходе работы выполнены анализ и формализация требований (функциональных, нефункциональных и неявных), спроектирована тестовая документация (покрытие игровых сессий, онлайн-синхронизации кода, чата, игры с ботом, песочницы и мобильной адаптивности), проведено функциональное тестирование с фиксацией результатов и составлены профессиональные баг-репорты для выявленных дефектов.

---

## Структура репозитория
* **`requirements.yml`** — формализованный перечень функциональных, нефункциональных и неявных (implicit) требований к веб-платформе.
* **`test-cases.yml`** — тестовые сценарии, покрывающие ключевой функционал: создание комнат, дуэли в реальном времени, игру с ботом, работу чата, проверку песочницы (sandbox), мобильную верстку и краевые случаи.
* **`testing-report.yml`** — отчет о результатах выполнения тест-кейсов со статусами `pass` и `fail`.
* **`bugreports.yml`** — отчеты об обнаруженных дефектах, оформленные по стандарту (Summary, Environment, Steps to Reproduce, Expected/Actual Result).

---

## Выполненные задачи и результаты
1. **Анализ требований:** Выделены ключевые пользовательские сценарии (создание комнат с выбором языка программирования, дуэли в реальном времени, игра с ботом, отслеживание результатов в лидерборде, приватные игры по ссылке).
2. **Тест-дизайн:** Создана полнофункциональная тестовая модель, включающая проверки изоляции кода (Sandbox), безопасность от редактирования кода соперника, неявные сценарии (дисконнект, перезагрузка страницы) и адаптивность под мобильные экраны.
3. **Выполнение тестов и локализация дефектов:** Выявлены дефекты в валидации кириллических символов при регистрации, сбои при обновлении лидерборда после матчей, некорректное поведение при разрыве соединения и проблемы адаптивной верстки на узких экранах.
4. **Документирование:** Все дефекты сгруппированы, описаны и привязаны к соответствующим шагам воспроизведения.
